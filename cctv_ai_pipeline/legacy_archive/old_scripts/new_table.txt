📊 AI/Python 개발자용 Supabase 데이터 적재 가이드
본 문서는 파이썬(Python) 파이프라인에서 AI 분석 결과(좌표, 위험점수, 영상 클립 등)를 Supabase 데이터베이스에 적재(Insert)할 때 참고해야 할 테이블 스키마 및 제약 조건 명세서입니다.
IMPORTANT
전체 공통 주의사항
자료형 매핑: Supabase의 int4는 Python의 int, int8은 Python의 int (또는 매우 큰 정수), timestamp는 datetime 객체나 ISO 8601 문자열로 넘겨주세요.
PK (Primary Key): 모든 테이블의 PK는 Identity 속성(자동 증가)이 걸려 있으므로, 파이썬에서 INSERT 할 때 PK 컬럼은 빼고 넘겨주시면 DB에서 알아서 번호를 땁니다.
1. 🚶‍♂️ pedaggr01h (CCTV 보행자 좌표 이력)
[AI 적재 핵심 ⭐] 프레임 단위로 추출된 객체(사람)의 2D 픽셀 좌표 및 3D 물리 좌표를 적재하는 테이블입니다.
컬럼명	자료형(Supabase)	NULL 여부	PK/FK	설명 및 적재 가이드
coord_id	int8	❌ NOT NULL	PK	좌표 고유 식별자 (INSERT 시 생략)
clip_id	int8	❌ NOT NULL	FK	영상 클립 테이블(vdoclip01m) 참조 ID
frame_id	int4	❌ NOT NULL	-	영상 내 프레임 번호 (예: 125)
video_id	int4	⭕ NULL	-	원본 업로드 영상 번호 (Optional)
pixels_json	jsonb	⭕ NULL	-	2D 픽셀 좌표. person_id를 Key로 묶어서 JSON으로 적재
(예: {"person_1": {"x": 1920, "y": 1080}})
bev_xyz_json	jsonb	⭕ NULL	-	3D 물리 좌표. person_id를 Key로 묶어서 JSON으로 적재
(예: {"person_1": {"x": 12.5, "y": 5.2, "z": 0.0}})
captured_at	timestamp	❌ NOT NULL	-	해당 프레임의 실제 캡처 시각
2. 🚨 mrkrisk01m (위험 점수)
[AI 적재 핵심 ⭐] 프레임별 AI 위험도 분석 결과를 적재하는 테이블입니다. 좌표 테이블(pedaggr01h)이 먼저 적재된 후(혹은 동시에) 연결되어야 합니다.
컬럼명	자료형(Supabase)	NULL 여부	PK/FK	설명 및 적재 가이드
risk_id	int8	❌ NOT NULL	PK	위험도 고유 식별자 (INSERT 시 생략)
coord_id	int8	❌ NOT NULL	FK	연결될 pedaggr01h의 coord_id
risk_score	float4	❌ NOT NULL	-	해당 프레임의 AI 산출 위험 점수 (예: 85.5)
risk_level	varchar	❌ NOT NULL	-	위험 등급 (예: "HIGH", "WARN", "SAFE")
reason_code	varchar	❌ NOT NULL	-	위험 탐지 사유 (예: "CROWD_DENSITY_HIGH")
total_count	int4	❌ NOT NULL	-	해당 프레임 내 감지된 전체 인원 수
detected_at	timestamp	❌ NOT NULL	-	위험 탐지 시점 (보통 captured_at과 동일)
3. 🎬 vdoclip01m (CCTV 영상 업로드 관리)
AI가 위험 상황(10초 이상 임계치 초과)을 감지하고 잘라낸 숏폼 클립(Clip)이나 실시간 임시 녹화본의 S3 경로를 저장합니다.
컬럼명	자료형(Supabase)	NULL 여부	PK/FK	설명 및 적재 가이드
clip_id	int8	❌ NOT NULL	PK	클립 고유 번호 (INSERT 시 생략)
zone_id	int8	❌ NOT NULL	FK	클립이 촬영된 구역 ID
factor_id	int8	⭕ NULL	FK	연관된 외부 요인(extfctr01h) ID
clip_type	varchar	❌ NOT NULL	-	클립 구분 ("TEMP": 임시저장, "RISK": 긴급클립)
s3_clip_url	text	❌ NOT NULL	-	아마존 S3에 업로드된 .mp4 클립 파일 URL
start_time	timestamp	❌ NOT NULL	-	클립 영상 시작 시간
end_time	timestamp	❌ NOT NULL	-	클립 영상 종료 시간
expires_at	timestamp	❌ NOT NULL	-	임시 클립 자동 파기 예정 시간
is_downloaded	bool	❌ NOT NULL	-	유저 다운로드 여부 (기본값: false)
is_deleted	bool	❌ NOT NULL	-	서버 자동 삭제 처리 여부 (기본값: false)
4. 📄 pstrprt01h (CCTV 사후 분석 보고서)
LLM 모델이 긴급 신고 후 상황을 분석하여 요약문과 보고서(PDF)를 생성할 때 적재합니다.
컬럼명	자료형(Supabase)	NULL 여부	PK/FK	설명 및 적재 가이드
report_id	int8	❌ NOT NULL	PK	보고서 고유 번호 (INSERT 시 생략)
alert_id	int8	❌ NOT NULL	FK	연결될 긴급 신고(emgalrt01h) ID
video_id	int4	⭕ NULL	-	원본 영상 번호
target_date	date	❌ NOT NULL	-	보고서 타겟 날짜 (YYYY-MM-DD)
llm_summary	text	⭕ NULL	-	LLM이 생성한 사후 요약 텍스트
s3_pdf_url	text	⭕ NULL	-	생성된 PDF의 S3 경로 URL
created_at	timestamp	❌ NOT NULL	-	보고서 생성 시각
5. 🚨 emgalrt01h (CCTV 긴급 신고 이력)
위험 감지 시 자동 긴급 신고 내역을 적재합니다. (백엔드에서 트리거할 수도 있음)
컬럼명	자료형(Supabase)	NULL 여부	PK/FK	설명
alert_id	int8	❌ NOT NULL	PK	신고 고유 번호
zone_id	int8	❌ NOT NULL	FK	구역 ID
alert_type	varchar	⭕ NULL	-	신고 종류 ("FIRE", "CROWD" 등)
is_resolved	bool	❌ NOT NULL	-	해결 여부 (기본값: false)
alerted_at	timestamp	❌ NOT NULL	-	신고 발생 시각
6. 🌤️ extfctr01h (CCTV 분석 외부 요인)
위험도에 영향을 미치는 외부 데이터(날씨, 행사 등)를 적재합니다.
 
컬럼명	자료형(Supabase)	NULL 여부	PK/FK	설명
factor_id	int8	❌ NOT NULL	PK	요인 고유 번호
market_id	int8	❌ NOT NULL	FK	시장 ID
video_id	int4	⭕ NULL	-	연관 영상 번호
target_date	date	❌ NOT NULL	-	적용 일자
weather_condition	varchar	⭕ NULL	-	날씨 상태 ("RAIN", "CLEAR" 등)
temperature	numeric	⭕ NULL	-	온도 (예: 25.4)
event_category	varchar	⭕ NULL	-	행사 종류
updated_at	timestamp	❌ NOT NULL	-	갱신 시각
